# 小蓝衣橱

一个无需安装依赖的手机友好型本地网页小应用。衣物、搭配记录和图片仅保存在打开应用的浏览器本机存储中。

## 开始使用

直接用浏览器打开 `index.html` 即可体验。想用手机浏览器访问电脑上的本地副本，可在项目目录运行 `python -m http.server 8000 --bind 0.0.0.0`，并在手机浏览器打开 `http://电脑的局域网IP:8000`（手机和电脑需连接同一 Wi-Fi）。

应用不依赖在线字体、接口或第三方服务。通过 HTTPS 静态网页首次打开后，可将它添加到手机主屏幕；应用外壳会缓存到本机，之后可离线打开。HTTPS 托管仅用于初次访问及安装，不会同步或上传衣橱数据。

首次打开会展示几件可用于体验的示例衣物。可以编辑这些单品，也可以从“我的”中清空本机数据后从空衣橱开始。

## 功能

- 衣橱：按分类筛选、搜索、排序、拍照或从相册导入，编辑并记录名称、季节、品牌、价格、评分、关键词、穿着次数和相关搭配。
- 本机图片处理：尝试通过图片边缘颜色识别去除纯色背景，不上传照片。背景复杂时效果有限，建议使用纯色背景照片。
- 搭配：选择衣橱单品或添加图片，直接拖动拼图内的图片调整位置；可双指捏合、点“+ / −”缩放，或按“↶ / ↷”每次旋转 15 度，也可移除单张图片。选择拼图底色后保存日常、工作或旅游穿搭；保存的拼图会保留调整后的位置、大小和角度，“今天穿了”会更新相关单品的穿着次数。
- 我的：查看衣物数量、估算总价值、累计穿着次数和已保存搭配。

## 隐私与容量

所有衣物和搭配数据保存在当前浏览器的 `localStorage`。卸载浏览器、清除网站数据或切换设备、浏览器后，数据不会自动同步；请避免存储大量或超大照片。
